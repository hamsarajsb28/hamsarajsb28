### 🚀 Featured Projects

<details>
<summary><b>🌾 KrishiMind – AI-Powered Smart Agriculture Platform</b></summary>

<br/>

An agriculture-focused application designed to provide useful insights through machine learning and natural language processing.

**Key Features:**

- Crop price forecasting using LSTM.
- Agricultural news sentiment analysis using DistilBERT.
- RAG-based agricultural chatbot.
- Context-aware responses using retrieved information.

**Technologies Used:**

Python, React.js, FastAPI, PostgreSQL, LangChain, ChromaDB, OpenAI Embeddings and GPT-4o-mini.

**Repository:** [View KrishiMind](https://github.com/hamsarajsb28/Krishimind)

</details>

<details>
<summary><b>📄 Skill Gap Finder – Resume Analysis and Matching</b></summary>

<br/>

A resume analysis application that compares resume content with job descriptions to identify relevant skills and potential skill gaps.

**Key Features:**

- Extracts text from PDF resumes.
- Processes resume and job description text.
- Uses CountVectorizer and cosine similarity for matching.
- Helps identify skills relevant to a job description.

**Technologies Used:**

Python, Flask, Scikit-learn, CountVectorizer, Cosine Similarity and pdfplumber.

**Repository:** [View Skill Gap Finder](https://github.com/hamsarajsb28/skill-gap-finder)

</details>
