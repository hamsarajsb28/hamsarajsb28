### 🚀 Featured Projects

<details>
<summary><b>🌾 KrishiMind — AI Crop Price Prediction System</b></summary>
<br/>

A full-stack application that predicts crop prices using historical mandi (market) data, built to give farmers and traders a data-backed view of price trends.

| Aspect | Detail |
|---|---|
| **Stack** | Python, Flask, Machine Learning, React, REST APIs |
| **Scale** | End-to-end pipeline from raw mandi data to live predictions |
| **Performance** | Preprocessing pipeline built specifically to improve model accuracy |
| **Security** | API-based separation between prediction service and frontend client |
| **Impact** | Deployed as a functional, real-time usable web application |
| **Repository** | [View Repository](#) |

Built the prediction backend as a Flask REST API and connected it to a React frontend, with a data preprocessing layer designed to reduce noise in historical pricing data before it reached the model — the kind of unglamorous work that ends up mattering most for accuracy.

</details>

<details>
<summary><b>📄 Skill Gap Analyzer — Resume Matching with NLP</b></summary>
<br/>

An NLP-driven system that compares resumes against job descriptions, scores the match, and surfaces missing skills.

| Aspect | Detail |
|---|---|
| **Stack** | Python, Scikit-learn, NLP, Flask |
| **Scale** | Processes unstructured PDF resume text into structured comparison data |
| **Performance** | CountVectorizer + cosine similarity for fast, explainable matching |
| **Security** | Local text extraction and processing, no third-party data exposure |
| **Impact** | Generates quantified match scores and actionable skill-gap reports |
| **Repository** | [View Repository](#) |

Extracted and cleaned text from PDF resumes, vectorized it alongside job descriptions, and used cosine similarity to produce a match score — turning a subjective "does this resume fit" question into something measurable.

</details>
